# 에이전트 인수인계 (compact 대체)

서브에이전트는 `/compact`가 없다. 대화가 쌓일수록 매 턴 비용이 커지므로 끊고 새로 시작한다.

## 언제
- 에이전트 사용 토큰이 약 10만을 넘었을 때
- 작업 단위 하나(예: CAD 구조 변경 + 렌더)가 끝났을 때
- 사용자가 compact·인수인계를 요청했을 때

## 절차
1. **실행 중이면 기다린다.** 렌더·빌드·업로드 중간에 끊지 않는다(반쯤 생성된 산출물이 남음). 기다리는 동안은 토큰이 들지 않는다.
2. **인수인계 파일을 쓰게 한다.** SendMessage로 지시: "현재 작업이 끝나면 `<작업폴더>/HANDOFF.md`를 한국어 40줄 이내로 쓰고 최종 보고 후 멈춰라."
   파일 내용:
   - 현재 구조와 핵심 수치
   - 주요 파라미터와 의미
   - 보기 번호 / 파일 목록 (산출물 경로)
   - 미검증 값
   - 남은 작업, 알려진 문제
3. **다음 작업은 새 에이전트로.** 새 Agent 호출 프롬프트 첫 줄: "`<작업폴더>/HANDOFF.md`를 먼저 읽고 이어서 작업하라." 이전 대화는 넘기지 않는다.
4. 새 작업이 끝나면 HANDOFF.md를 갱신하게 한다.

## 규칙
- 에이전트에게 맡길 때 짧은 단위로 끊는다. 한 에이전트에 지시를 계속 덧붙이지 않는다.
- 보고는 10줄 이내로 요구한다. 메인 대화에는 결과만 전한다.
- 에이전트 보고를 그대로 믿지 말고 산출물(프리뷰 이미지, 수치)을 메인에서 직접 확인한다.
- 메인 세션 자체를 줄이려면 사용자가 `/compact` 또는 `/clear`를 입력해야 한다(에이전트가 대신 못 함).

## 현재 사용처
- CAD: `cad/HANDOFF.md` (OpenSCAD는 `.claude/skills/openscad` 스킬로 작업)
