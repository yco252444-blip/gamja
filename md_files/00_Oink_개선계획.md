## 1. Oink의 목표 재정의
- **MK1(발표자료)**: "온디바이스 AI가 히터를 예측 제어해 월 1,500원대 절전".
- **Oink**: "**측정으로 입증된 히터 듀티 감축 + 안전 3중 방어 + 냄새(가스) 기반 경보**". AI는 *기준선을 이겼을 때만* 전면에 내세운다. 못 이기면 "규칙 제어 + 급변(투입물) 감지"로 서사를 정직하게 낮춘다.
- 승부 지점(차별 후보, 07 조사): ①가스 센서 기반 폐루프 ②**실측 전력 A/B 비교** ③투입물 급변 대응. 상용품(린클 등)이 앱·활성도·에러알림은 이미 표방하므로 "센서+앱"으로는 창의성 방어가 안 된다.

## 3. 목표 아키텍처 (Oink v2, 제안)
```
[12/24V DC 어댑터] ─ 퓨즈 ─ 서모스탯(KSD301) ─ 열퓨즈 ─ [히터 패드] ─ INA219(션트) ─ MOSFET/SSR ─ GND
                                              ▲ 독립 하드웨어 차단(SW 무관)
[5V ≥2A] ─ XIAO ESP32S3 ─ DS18B20(12bit) / DHT11(외부) / MQ-137(분압) / (선택)MQ-136
   ESP32: 히스테리시스+급변 감지+안전 게이트(과열·센서무효·워치독) → 히터 출력  ← 서버 없이 동작
   ESP32 → MQTT(전용 AP) → 노트북/Pi 대시보드(로그·시각화·A/B 표시) [제어 경로 아님]
```
※ 부품 모델·전원 규격은 확인 전 **가정**. 실제 부품 정보를 받으면 핀맵·배선도를 이 구조에 맞춰 확정한다.
