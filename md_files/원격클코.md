# 모바일/태블릿에서 장거리 데스크톱의 Claude Code·Orca 원격 조작

## 상황
네트워크로 연결돼 있기만 하면, 물리적으로 멀리 떨어진 데스크톱/노트북에서 돌아가는 Claude Code(또는 Orca 안의 Antigravity/agy)를 폰이나 태블릿으로 조작하고 싶을 때.

두 갈래로 나눠서 봐야 한다.

---

## 1. Claude Code 자체 — 공식 "Remote Control" 기능 (미검증: 정확한 설정 방법)

Claude Code 계정에 **Remote Control**을 연결해두면, 폰/태블릿(웹 claude.ai/code 또는 모바일)에서 그 데스크톱에서 돌아가는 Claude Code 세션을 보고 메시지를 보낼 수 있다.

- 즉 Claude Code 부분은 Anthropic 공식 기능으로 지원된다.
- 다만 **정확한 활성화 절차(설정 메뉴 위치 등)는 이 문서에서 확인 안 됨** — 실제로 켜볼 사람이 확인 후 이 문서에 추가할 것.

## 2. Orca(서드파티 GUI 멀티에이전트 앱) — 일반 원격 접속 방법 필요

Orca는 Anthropic이 아니라 서드파티라 위 Remote Control로는 안 된다. Orca UI 자체를 폰에서 조작하려면 일반적인 원격 접속 방법을 조합해야 한다.

### 추천 방법 — Tailscale + SSH (터미널 기반, 가볍고 빠름)

1. **Tailscale**(또는 다른 VPN) 설치 — 데스크톱과 폰을 같은 가상 네트워크로 묶는다.
2. 데스크톱에서 `tmux`(또는 `screen`) 세션 안에 Orca가 돌리는 agy/터미널 에이전트를 띄워둔다.
3. 폰에 **SSH 클라이언트**(Termius, Blink Shell 등) 설치 → 그 tmux 세션에 attach.

이러면 Orca의 GUI 자체는 아니지만, **터미널 기반 에이전트 조작은 폰에서 그대로 가능**하다.

### 대안 — 화면 통째로 스트리밍 (무겁고 느림)

Orca GUI 화면 자체를 폰에 띄우고 싶으면 RDP·AnyDesk·Chrome 원격 데스크톱처럼 화면 전체를 스트리밍하는 방법밖에 없다. 터미널 방식보다 훨씬 무겁고 느리다.

## 노트북에서 데스크톱 성능으로 Claude Code 쓰기 — 따라하기 가이드

> 목표: **무거운 일(Claude Code, 빌드, arduino-cli 컴파일)은 전부 데스크톱이 하고, 노트북은 화면·키보드 역할만** 하게 만든다.
> 노트북에는 브라우저와 VS Code만 있으면 된다.
>
> 전제: 데스크톱·노트북 둘 다 Windows 10/11, **둘 다 같은 사람(같은 Claude 계정) 소유**.
> 상태: 아래 절차는 공식 문서·일반적인 Windows 설정 기준으로 작성함. **이 두 대의 PC에서 실제로 해본 건 아니므로 미검증.** 해보고 안 되는 곳은 이 문서에 메모할 것.

### 0. 먼저 고르기 — 방법이 두 개 있음

| | 방법 1: Remote Control | 방법 2: VS Code 원격 접속 (Tailscale + SSH) |
|---|---|---|
| 노트북에서 보이는 것 | 브라우저의 Claude 채팅 화면 | **VS Code 전체** (파일 트리, 편집기, 터미널) |
| 세팅 난이도 | 5분 | 30분 |
| 필요한 것 | Claude Pro/Max 구독 | Tailscale 무료 계정 |
| 밖에서(다른 와이파이) 접속 | 됨 | 됨 (Tailscale 덕분) |
| 추천 용도 | "시켜놓고 결과만 보기", 폰으로 확인 | **실제 개발** (코드 보면서 고치기) |

**추천: 방법 1부터 해서 바로 쓰고, 여유 있을 때 방법 2까지 세팅.** 둘은 같이 써도 된다.

### 1. 데스크톱 공통 준비 (한 번만)

데스크톱에서 **PowerShell을 관리자 권한으로** 연다 (시작 버튼 우클릭 → "터미널(관리자)").

#### 1-1. 필요한 프로그램 설치

```powershell
winget install Git.Git
winget install Microsoft.VisualStudioCode
winget install Tailscale.Tailscale
```

설치 후 **PowerShell 창을 닫았다가 다시 연다** (PATH 갱신).

#### 1-2. Claude Code 설치 + 로그인

```powershell
irm https://claude.ai/install.ps1 | iex
```

창을 다시 연 다음:

```powershell
claude --version
claude
```

`claude` 첫 실행 때 브라우저가 뜨면 **claude.ai 계정(Pro/Max)** 으로 로그인한다. API 키 로그인은 Remote Control이 안 된다.

#### 1-3. 데스크톱이 잠들지 않게 (중요!)

데스크톱이 절전 모드로 가면 노트북에서 아무것도 안 된다.

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

(모니터 꺼지는 건 상관없음. **절전/최대 절전만** 끄면 된다.)

### 2. 방법 1 — Remote Control (5분 컷)

#### 데스크톱에서

작업할 프로젝트 폴더로 가서 실행:

```powershell
cd C:\작업할\프로젝트\폴더
claude remote-control
```

- 처음에 `Enable Remote Control? (y/n)` 나오면 `y`
- 화면에 **세션 URL과 QR코드**가 뜬다 (스페이스바로 QR 표시 켜고 끄기)
- **이 창은 닫지 말고 켜둔다.** 닫으면(Ctrl+C) 원격 연결도 끊긴다.

이미 `claude`를 켜서 쓰고 있는 중이면, 그 안에서 `/remote-control` (줄여서 `/rc`) 입력해도 된다.

#### 노트북에서

1. 브라우저로 **https://claude.ai/code** 접속 → 데스크톱과 **같은 계정**으로 로그인
2. 세션 목록에 데스크톱 세션이 보인다 → 클릭
3. 채팅하듯 시키면 **데스크톱이** 코드를 읽고, 고치고, 명령을 실행한다

폰도 똑같다: Claude 앱 설치 → 데스크톱 화면의 QR 찍기.

#### 알아둘 점
- 파일 편집·명령 실행은 전부 데스크톱에서 일어난다. 노트북은 채팅만.
- 코드를 직접 눈으로 보면서 고치고 싶으면 → 방법 2.
- 네트워크가 잠깐 끊겨도 자동 재연결됨. 서버 모드(`claude remote-control`)는 인터넷이 10분 넘게 끊기면 종료되니 다시 실행.
- 에러 `Remote Control requires a claude.ai subscription` → `claude auth login` 다시 하고 claude.ai 옵션 선택.

### 3. 방법 2 — VS Code로 데스크톱에 원격 접속 (진짜 개발환경)

노트북 VS Code에서 **데스크톱 폴더를 내 컴퓨터처럼** 열고, 터미널도 데스크톱 것을 쓴다. 노트북 성능은 거의 안 씀.

#### 3-1. Tailscale로 두 PC 묶기 (집 밖에서도 접속되게)

**데스크톱, 노트북 둘 다:**
1. Tailscale 설치 (노트북: `winget install Tailscale.Tailscale`)
2. 작업표시줄 트레이의 Tailscale 아이콘 → **Log in** → **둘 다 같은 계정**(구글 계정 등)으로 로그인

**데스크톱에서** 이름/주소 확인:

```powershell
tailscale ip -4
tailscale status
```

- `100.x.x.x` 형태 IP와 데스크톱 이름(예: `my-desktop`)이 나온다 → **메모해둘 것**

#### 3-2. 데스크톱에 SSH 서버 켜기 (관리자 PowerShell)

```powershell
# SSH 서버 설치
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

# 켜고, 부팅할 때 자동으로 켜지게
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic

# 접속했을 때 cmd 대신 PowerShell이 뜨게
New-ItemProperty -Path "HKLM:\SOFTWARE\OpenSSH" -Name DefaultShell -Value "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -PropertyType String -Force
```

방화벽 규칙은 설치할 때 자동으로 생긴다. 확인:

```powershell
Get-NetFirewallRule -Name *ssh*
```

**데스크톱 사용자 이름 확인** (SSH 로그인할 때 씀):

```powershell
whoami
```

`desktop-abc\홍길동` 처럼 나오면 `\` 뒤의 **`홍길동`** 이 사용자 이름.

> 비밀번호 주의: 마이크로소프트 계정으로 로그인하는 PC면, SSH 비밀번호는 **PIN이 아니라 마이크로소프트 계정 비밀번호**다.

#### 3-3. 노트북에서 접속 테스트

노트북 PowerShell (일반 권한):

```powershell
ssh 홍길동@my-desktop
```

- `my-desktop` 대신 `100.x.x.x` IP를 써도 됨
- 처음에 `Are you sure you want to continue connecting` → `yes`
- 비밀번호 입력 → 데스크톱 PowerShell 프롬프트가 뜨면 성공
- `exit` 로 나오기

#### 3-4. 노트북 VS Code로 연결

1. 노트북에 VS Code 설치: `winget install Microsoft.VisualStudioCode`
2. VS Code 확장(Extensions)에서 **Remote - SSH** (Microsoft) 설치
3. `F1` → `Remote-SSH: Connect to Host...` → `홍길동@my-desktop` 입력
4. 플랫폼 물어보면 **Windows** 선택 → 비밀번호 입력
5. 왼쪽 아래 초록색에 `SSH: my-desktop` 뜨면 연결 완료
6. `File → Open Folder` → 데스크톱의 프로젝트 폴더 선택

이제 VS Code 안의 터미널(`Ctrl+\``)은 **데스크톱 터미널**이다. 여기서:

```powershell
claude
```

→ Claude Code가 데스크톱 성능으로 돈다. 편집기에서 바뀌는 파일도 바로 보인다.

#### 3-5. (선택) 비밀번호 매번 치기 귀찮으면 — SSH 키 등록

**노트북에서:**

```powershell
ssh-keygen -t ed25519
# 엔터 3번 (기본 위치, 비밀번호 없음)
type $env:USERPROFILE\.ssh\id_ed25519.pub
```

출력된 한 줄(`ssh-ed25519 AAAA...`)을 복사.

**데스크톱에서 (관리자 PowerShell)** — 데스크톱 계정이 관리자 계정인 경우(대부분 개인 PC가 이 경우):

```powershell
Add-Content -Path C:\ProgramData\ssh\administrators_authorized_keys -Value "여기에_복사한_한줄_붙여넣기"
icacls C:\ProgramData\ssh\administrators_authorized_keys /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"
```

(관리자 아닌 계정이면 대신 데스크톱의 `C:\Users\홍길동\.ssh\authorized_keys` 파일에 붙여넣기.)

노트북에서 `ssh 홍길동@my-desktop` 했을 때 비밀번호 안 물어보면 성공.

### 4. 이 프로젝트(XIAO ESP32S3) 쓸 때 주의

- **보드 USB는 데스크톱에 꽂는다.** arduino-cli 컴파일·업로드가 데스크톱에서 돌기 때문. 노트북에 꽂으면 데스크톱에서 COM 포트가 안 보인다.
- 원격에서 업로드할 땐 옆에 사람이 없을 수 있으니, **액추에이터(릴레이/모터) 물리 시험은 누가 보드 옆에 있을 때만** (CLAUDE.md 규칙).
- 한 보드에 두 세션이 동시에 붙지 않게: 데스크톱 로컬 claude와 원격 claude를 동시에 돌리면서 둘 다 업로드시키지 말 것.

### 5. 매일 쓰는 순서 (요약)

**방법 1만 쓸 때**
1. 데스크톱 켜져 있는지 확인
2. 데스크톱에서 `claude remote-control` (프로젝트 폴더에서) — 한 번 켜두면 계속 둬도 됨
3. 노트북 브라우저 → claude.ai/code → 세션 클릭

**방법 2 쓸 때**
1. 데스크톱 켜져 있는지 + Tailscale 켜져 있는지 확인
2. 노트북 VS Code → 왼쪽 아래 `><` 아이콘 → `my-desktop` 연결
3. 터미널에서 `claude`

### 6. 안 될 때

| 증상 | 확인할 것 |
|---|---|
| claude.ai/code에 세션이 안 보임 | 데스크톱에서 `claude remote-control` 창이 켜져 있나 / 노트북과 같은 계정인가 |
| `Remote Control requires a claude.ai subscription` | `claude auth login` → claude.ai 선택. 환경변수에 `ANTHROPIC_API_KEY` 있으면 지우기 |
| `ssh: connect ... timed out` | 둘 다 Tailscale 로그인·연결 상태인가 (`tailscale status`) / 데스크톱이 잠들었나 |
| `Connection refused` | 데스크톱에서 `Get-Service sshd` → Running 인가. 아니면 `Start-Service sshd` |
| `Permission denied` | 사용자 이름(`whoami`의 `\` 뒤) 맞나 / 비밀번호가 PIN 말고 MS 계정 비밀번호인가 |
| VS Code 연결이 계속 도는 중 | `F1` → `Remote-SSH: Kill VS Code Server on Host` 후 다시 연결 |
| 한참 뒤 접속이 안 됨 | 데스크톱 절전 설정 (1-3) 다시 확인, Windows 업데이트로 재부팅됐는지 |
