# Oink 시스템 구성도

작성: 2026-10-25. 대상: 제14회 Creative Space G 본대회(11/6~7) 시제품.
표기: **(확정)** 팀 합의 / **(제안)** 이 문서의 제안 / **미검증** 실물 확인 필요.

---

## 1. 한 줄 요약

음식물 처리 챔버 안의 **심부 온도 · CO₂ · 부패 가스**를 읽고, ESP32-S3가 **히터를 ON/OFF**해서 미생물이 일할 때만 데운다. 소비 전력은 **INA219**로 실측하고, 상태는 앱/대시보드와 **반려 미생물 캐릭터**로 보여준다.

## 3. 구성 요소

### 3-1. 센서 (입력)
| 센서 | 측정 | 연결 | 왜 필요한가 | 보유 |
|---|---|---|---|---|
| **DS18B20** | 음식물 심부 온도 | 1-Wire | 공기 온도가 아닌 미생물이 있는 곳의 실제 온도 → 히터 ON/OFF 기준 | ✅ 2개 |
| **CM1106S** | CO₂ 농도 0~10,000ppm | UART 9600bps, 5V 전원 | 미생물 호흡량 = 분해 활성도. **증가 속도(ppm/분)**로 상태 판정. **자동 보정(ABC) 꺼야 함**(§11) | ✅ 3개 |
| **MQ-136** 또는 **MQ-137** | 부패 가스(H₂S / NH₃) | 아날로그(ADC, **분압 필요**) | 부패(혐기화) 징후 → 미생물 죽기 전 경고 | MQ-137 ✅ / MQ-136 ❌ |
| **INA219** | 히터 전압·전류·전력 | I²C | **절전 효과를 실측**으로 증명 (26V·3.2A 한도, 매트 1.7A OK) | ✅ 1개 |
| **BME280** | 외기 온습도 | I²C | 실내 온도에 따른 열 손실 보정, 비교 기준 | ✅ 1개 |
| 무게 센서 (팀원 제안) | 로드셀 + HX711 | 2선 디지털 | 투입량 + **분해에 따른 무게 감소**로 진행도 보조 확인. 단, 제안서에서 "무게만 재는 기존 제품"과 대비했으므로 **주 지표가 아닌 보조**로 설명 | ❌ 구매 |

> MQ-136(제안서에 적힌 센서)을 살지, 보유한 MQ-137로 갈지는 **미결정**. MQ 계열은 48시간 예열 권장.

### 3-2. 액추에이터 (출력)
| 장치 | 사양 | 제어 | 비고 |
|---|---|---|---|
| **히터 — 미결정 (후보 2개, §11-1 비교)** | ① 캡톤 히터 24V 14W (보유, 0원) ② USB 육묘 매트 5V 8.5W (30,160원) | MOSFET **ON/OFF** | 어느 쪽이든 회로 구조는 같음 |
| **5V 팬 (필수로 격상)** | 소형 | MOSFET ON/OFF | 닫힌 챔버는 CO₂가 수십 분 안에 센서 상한을 넘음(§11-3) → 측정 후 환기 사이클 필요 |
| 교반 모터 (선택) | 서보 등 | PWM | 제안서에 있으나 우선순위 낮음 |

### 3-3. 제어기
- **XIAO ESP32-S3**: 센서 수집 → 상태 판정 → 히터 제어 → 로그/전송. 보유 4개(1개 사용, 나머지 예비).
- 인터넷이 끊겨도 **제어 루프는 보드 안에서 계속 동작**(로컬 자율 제어). 대회장 Wi-Fi가 불안정하다고 안내받았으므로 시연은 로컬 중심.

## 4. 전원·배선도 (제안)

아래는 **USB 매트(5V) 기준**. 캡톤 히터를 쓰면 히터 쪽만 24V 어댑터로 바뀌고(INA219 위치 동일), 보드·센서용 5V는 별도로 둔다 → §11-1.

```
 5V 3A 어댑터 (+) ──┬── INA219 VIN+ ── VIN− ──► 히팅 매트 (+)
                    │                            히팅 매트 (−) ──► IRLZ44N Drain
                    │                                              IRLZ44N Source ──► GND
                    │                                              IRLZ44N Gate ◄── 100Ω ◄── XIAO D3
                    │                                                          └── 10kΩ ── GND (풀다운: 부팅 시 OFF)
                    ├── CM1106S 5V
                    ├── MQ 센서 5V ── AO ──[분압 저항]──► XIAO A0
                    └── XIAO 5V 핀 (보드 전원)

 XIAO 3V3 ── DS18B20 VDD,  DQ ──► XIAO D2 (4.7kΩ 풀업)
 XIAO D4(SDA)/D5(SCL) ── INA219, BME280, OLED (I²C 공유)
 XIAO D6(TX)/D7(RX) ── CM1106S RX/TX
 ※ 모든 GND 공통
```

| 항목 | 값 | 판단 |
|---|---|---|
| 5V 전류 합계 | 매트 1.7A + MQ 0.17A + CM1106S <0.05A + XIAO(Wi-Fi 피크) ~0.35A + 팬 ~0.15A ≈ **2.4A** | 3A는 빠듯 → **4A 권장**(§11-2) |
| 히터 하드웨어 차단 | 매트 자체 최고 50℃ + **KSD301 서모스탯(NC)** 직렬 | SW와 무관하게 과열 차단 |
| 핀 배정 | 위 표는 **제안**. 펌웨어 `config.h`의 DS18B20=D2와 일치 | 조립 시 확정 |

저항은 대회 현장에서 제공된다(OT). 게이트·풀다운·분압·풀업 저항은 현장 수급.

## 5. 제어 로직

### 5-1. 히터 ON/OFF (펌웨어 `control_core.h`, 구현됨)
```
심부 온도 ≤ 목표 − 0.5℃  → 히터 ON
심부 온도 ≥ 목표          → 히터 OFF
- 최소 유지 시간 10초 (잦은 토글 방지)
- 연속 가열 상한 → 강제 휴식 (매트용으로 20~30분으로 늘릴 예정, 실측 후 확정)
- 센서 실패 / 과열 / 부팅 직후 → 히터 잠금 OFF
```

### 5-2. 미생물 상태 판정 (구현 예정)
| 상태 | 판정 신호 | 동작 |
|---|---|---|
| 🟢 활발히 분해 중 | CO₂ 상승 ↑, 심부 온도 스스로 ↑ | 자가발열 활용 → 히터 듀티 줄임 (**절전 핵심**) |
| 🟡 활성 저하 | CO₂ 상승 거의 없음, 온도 ↓ | 목표 온도 유지 + 알림 |
| 🔴 부패 의심 | CO₂ 정체 + 가스 ↑ | 환기/교반 + 해결책 알림 |
| ✅ 분해 완료 | CO₂ 기준선 복귀 | 절전 대기 |

1단계는 **규칙 기반**(기준값 비교)으로 만들고, 실측 로그가 쌓이면 TFLite 분류 모델과 정확도를 비교해 나은 쪽을 쓴다. 기준값(ppm/분, ℃)은 실측으로 정한다(현재 미정).

### 5-3. 우선순위
```
① 안전 (과열·센서 실패 → 즉시 OFF)   ← 항상 최우선, AI 개입 없음
② 히터 ON/OFF (심부 온도)
③ 상태 판정 → 목표 온도·알림 조정
④ 로그·전송 (끊겨도 ①~③은 계속)
```

## 8. 절전 검증 (시연 핵심)
- 챔버 A(기존 방식: 상시/공기 온도 기준) vs 챔버 B(Oink 제어)를 **같은 조건**으로 동시 운전.
- INA219 누적 **Wh**, 히터 가동률, 심부 온도 유지, CO₂ 활성도를 비교 → 대시보드에 두 그래프를 나란히.
- 챔버 2개면 매트·INA219가 각 2개 필요. INA219는 1개 보유 → **추가 1개 구매 또는 B만 측정**할지 결정 필요.

## 11. 정밀 검증 (데이터시트 + 물리 계산)

근거: `datasheets/` 폴더 데이터시트. **추정**은 계산 가정이 있는 값이며 실측으로 확인해야 한다.

### 11-1. 히터 후보 비교
| 항목 | ① 캡톤 히터 24V 14W (보유) | ② USB 육묘 매트 5V 8.5W |
|---|---|---|
| 비용 | **0원** (어댑터 포함 보유) | 30,160원 + 5V 4A 어댑터 |
| 출력 | 14W | 8.5W (INA219 션트 전압 강하로 실제 ~7.8W, 추정) |
| 표면 온도 | 정격 50℃, **최대 180℃** → 계속 켜지면 과열 가능 | **45~50℃에서 스스로 제한** |
| 방수·외관 | 맨 필름 → 방열판에 붙이고 숨겨야 함 | PVC 방수, 완제품 외관 |
| 전원 분리 | **24V 별도 레일** → 히터 스위칭이 센서 5V를 흔들지 않음 | 센서와 **같은 5V** → 리플·전압 강하 대책 필요 |
| INA219 | 0.58A, 24V (26V 한도 안이지만 여유 2V) | 1.7A, 5V (여유 큼) |
| 예열 시간 (추정) | 약 1.5시간 | 약 3시간 |
| 안전 필수 부품 | **KSD301 필수** | KSD301 권장 |

**판단**: 성능·비용·전원 안정성은 ①, 외관·자체 안전은 ②. ②를 고르면 §11-2의 전원 대책을 같이 해야 한다.

### 11-2. 전원
| 확인 항목 | 근거 | 결론 |
|---|---|---|
| CM1106S 전원 리플 | 데이터시트: 리플 **<50mV**, 전원 3.5~5.5V, 전류 <50mA | 매트(1.7A)를 같은 5V에서 켜고 끄면 리플 초과 가능 → **센서 옆 0.1µF + 전원단 470~1000µF 전해 콘덴서** |
| MQ-137 히터 | RH 30Ω, PH ≤950mW → 5V에서 약 **167mA** | 5V 예산에 반영 |
| 5V 총합 (매트 안) | 1.7 + 0.17 + 0.05 + 0.35 + 0.15 ≈ 2.4A | **5V 4A 어댑터**. 3A는 여유 부족 |
| XIAO 5V 핀 | 회로도 블록도: USB VBUS가 다이오드 없이 5V 핀과 연결 | 외부 5V로 보드를 먹이면서 PC USB를 동시에 꽂으면 **역전류 위험** → 펌웨어 업로드 땐 외부 5V 분리, 또는 외부 5V에 쇼트키 다이오드 |
| 퓨즈 | 배선도에 아직 없음 | 히터 라인에 퓨즈 추가 (매트 2.5A / 캡톤 1A급, 추정) |

### 11-3. CO₂ 측정 방식 — 설계 변경 필요
- CM1106S 측정 범위 **0~10,000ppm**, 동작 온도 **-10~50℃**, 습도 **0~95% 결로 없음**.
- **포화 계산 (추정)**: 음식물 수백 g이 활발히 분해되면 CO₂를 대략 시간당 수십 mL 낸다. 1L 공간이 닫혀 있으면 시간당 2만 ppm 이상 오르므로 **10~30분이면 10,000ppm 상한**에 닿는다.
- **해결 — 닫힘·측정·환기 사이클**: 환기구를 닫고 5분 동안 CO₂ 상승 기울기(ppm/분)를 잰 뒤 팬으로 환기한다. 퇴비 호흡률 측정에 쓰는 "폐쇄 챔버법"과 같은 원리. 기울기가 곧 활성도.
- **자동 보정(ABC) 끄기**: 데이터시트상 ABC는 "7일 중 최저값 = 400ppm"으로 기준을 다시 잡는다. 챔버 안은 400ppm까지 내려가지 않으므로 ABC가 켜져 있으면 값이 틀어진다 → 부팅 시 UART 명령 `0x10`으로 끄기.
- **결로·온도**: 40℃ 습한 공기가 차가운 센서 면에 닿으면 결로가 생긴다(데이터시트 위반). 센서는 챔버 **안이 아니라 환기 통로 쪽**에 두고 방수 필터 면을 아래로. 50℃ 넘는 곳 금지.
- 첫 측정까지 ≤30초, 측정 주기 1초.

### 11-4. "자가발열 → 절전" 주장 점검 — 서사 보완 필요
- **계산 (추정)**: CO₂ 1g이 나올 때 열은 약 10kJ. 하루 1~3g이면 평균 **0.1~0.4W**.
- 단열 챔버의 열 손실은 20℃ 온도차에서 **약 4~6W**(추정). 미생물 열은 그 **5% 안팎**이라, 1~2L에서는 "히터를 꺼도 온도가 유지·상승"하는 구간이 거의 생기지 않는다. 자가발열은 수십 L 이상의 큰 더미에서나 뚜렷하다.
- **결론**: 절전 효과의 주 근거를 바꿔야 한다.
  1. **분해 완료·투입 없음 감지 → 대기 온도로 낮춤** (가장 큰 절감 예상)
  2. **공기 온도 대신 심부 온도 기준** → 과가열 방지
  3. 자가발열 활용은 보조 효과로만 언급
- 제안서와 앱 목업의 "자가발열 구간 절전" 문구도 이에 맞춰 조정 권장.

### 11-5. 센서 연결
| 항목 | 근거 | 결론 |
|---|---|---|
| MQ 아날로그 → ADC | ESP32-S3 ADC 최대 감쇠(ATTEN3) 유효 범위 **0~2,900mV** | 5V 출력 분압: **10kΩ / 12kΩ → 최대 2.73V** (10k/20k는 3.33V라 초과) |
| ADC 핀 | Wi-Fi 사용 중 ADC2 불가 | MQ는 **D0~D? 중 ADC1 핀**(D0=GPIO1) 사용 ✅ |
| MQ-137 | 측정 5~500ppm NH₃, 예열 **48시간 이상**, 온습도 영향 큼 | 대회 2일 전부터 상시 통전, 절대 농도보다 **추세** 사용 |
| DS18B20 | 전원 3.0~5.5V, ±0.5℃, 풀업 약 4.7~5kΩ | 3.3V + 4.7kΩ ✅. 젖은 음식물에 꽂으므로 **방수 스테인리스 프로브형** 필요 → 보유품 형태 확인 |
| CM1106S UART | TTL 3.3V/5V 호환, 9600bps | XIAO D6/D7(GPIO43/44)에 직결 가능 ✅. 이 핀은 부팅 로그가 나오는 UART0이라 부팅 직후 잡음 1회 → 무시하면 됨 |
| DS18B20 핀 D2 | GPIO3은 스트래핑 핀(JTAG 선택, eFuse 설정 시에만 영향) | 기본 설정에선 문제없음 ✅ |

### 11-6. MOSFET (IRLZ44N)
- 데이터시트: Vgs(th) **1.0~2.0V**, Rds(on) 0.022Ω@10V / 0.025Ω@5V / **0.035Ω@4V**. 3.3V 값은 규격에 없음.
- 3.3V에서 Rds(on)을 0.1Ω 이하로 보수적으로 잡으면 (추정): 매트 1.7A → 손실 ≤0.29W, 온도 상승 ≤18℃(RθJA 62℃/W) → **방열판 없이 가능**. 캡톤 0.58A → 0.03W로 무시 가능.
- 게이트 100Ω + 풀다운 10kΩ 유지(부팅 시 OFF 보장).

### 11-7. A/B 실험 수량
- 챔버 2개면 INA219 **2개**(주소 0x40/0x41, 모듈의 A0 패드로 변경), 히터 2개, DS18B20 2개(보유), CO₂ 2개(보유 3) 필요.
- INA219는 1개 보유 → **1개 추가 구매**.
