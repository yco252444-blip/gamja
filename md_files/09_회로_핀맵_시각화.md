## 3. 센서 및 액추에이터별 세부 결선도 (Detailed Wiring)

### 3-1. 24V 가열 및 3중 안전 차단 회로 (Heater & 3-Tier Safety)
> **안전 제1원칙**: 소프트웨어가 다운되거나 먹통이 되어도 물리적으로 화재를 차단하는 3중 방어망.

```
 [24V (+) 어댑터]
       │
   [ 퓨즈 2A ] (과전류 1차 차단)
       │
   [ KSD301 서모스탯 ] (45~50℃ 기계식 자동 OFF 바이메탈, 2차 차단)
       │
   [ 1회용 열퓨즈 ] (70℃ 초과 시 영구 차단 최후 보루, 3차 차단)
       │
   ┌───┴────────────────────────┐
   │ INA219 (V+ 핀)             │ (하이사이드 전압/전류 계측)
   │ 션트 저항 (0.1Ω)           │
   │ INA219 (V- 핀)             │
   └───┬────────────────────────┘
       │
   [ 캡톤 필름 히터 (24V 14W, 41.1Ω) ]
       │
       ├──► IRLZ44N Drain (D)
            IRLZ44N Source (S) ──► [ 24V GND ]
            IRLZ44N Gate (G)
                 ▲
                 ├── [ 10kΩ 풀다운 저항 ] ──► [ GND ] (부팅 시 오동작 방지)
                 └── [ 100Ω 게이트 저항 ] ──► [ XIAO D8 (GPIO7) ]
```

---

### 3-2. I2C 다중 센서 버스 결선 (D4 / D5)
> **동일 버스 3개 장치 연결**: 주소가 서로 달라 충돌 없이 2가닥 선으로 동시 제어.

```
   XIAO ESP32S3                     I2C 센서 어레이
  ┌──────────────┐
  │   3.3V (VDD) ├──────┬──────────────┬──────────────┐
  │   GND        ├──────┼──────┬───────┼──────┬───────┼──────┐
  │   D4 (SDA)   ├──────┼──────┼─ SDA  │      │       │      │
  │   D5 (SCL)   ├──────┼──────┼───────┼─ SCL │       │      │
  └──────────────┘      │      │       │      │       │      │
                   ┌────┴──────┴──┐ ┌──┴──────┴──┐ ┌──┴──────┴──┐
                   │    INA219    │ │    BME280   │ │ 0.96" OLED │
                   │  (전력 계측) │ │  (온습도)  │ │ (상태화면) │
                   │  Addr: 0x40  │ │ Addr: 0x76 │ │ Addr: 0x3C │
                   └──────────────┘ └─────────────┘ └─────────────┘
```

### 3-3. CM1106S4 NDIR CO₂ 센서 결선 (UART: D6 / D7)
> **미생물 호흡 활성도 측정**: 5V 구동, 3.3V 로직 레벨로 ESP32 직결 가능.

```
       [ 5V 2A 레일 ] ─────────────────────────► CM1106S4 Pin 1 (VCC)
       [ 공통 GND ]   ─────────────────────────► CM1106S4 Pin 2 (GND)
   XIAO D7 (GPIO44, RX) ◄────────────────────── CM1106S4 Pin 3 (TX, 3.3V 레벨)
   XIAO D6 (GPIO43, TX) ──────────────────────► CM1106S4 Pin 4 (RX, 3.3V 허용)
```

---

### 3-4. DS18B20 심부온도 센서 결선 (OneWire: D2)
> **방수 스테인리스 프로브**: 미생물 배양토 내부 심부온도 측정 (12-bit 정밀 모드).

```
       [ 3.3V VDD ] ─────────┬─────────────────► DS18B20 VCC (빨강)
                             │
                         [ 4.7kΩ ] (풀업 저항)
                             │
   XIAO D2 (GPIO3) ──────────┴─────────────────► DS18B20 DATA (노랑/흰색)
       [ 공통 GND ] ───────────────────────────► DS18B20 GND (검정)
```

---

### 3-5. MQ-137 암모니아(악취) 센서 안전 분압 회로 (ADC: D0)
> **ESP32 ADC 보호(최대 2.9V)**: 5V 출력 신호를 2.7V 이하로 강하.

```
       [ 5V 2A 레일 ] ─────────────────────────► MQ-137 VCC (히터 180mA 구동)
       [ 공통 GND ]   ─────────────────────────► MQ-137 GND
       
       MQ-137 Analog Out (0~5V)
               │
           [ 10kΩ ]
               │
               ├───────────────────────────────► XIAO D0 (GPIO1, ADC1_CH0)
               │                                  (최대 전압 2.72V로 안전)
           [ 12kΩ ]
               │
           [ 공통 GND ]
```

### 3-6. 직관적 사용자 UI 장치 (WS2812B & 블로워 팬)

```
 [ 신호등 RGB LED (WS2812B) ]
       5V  ◄── [ 5V 2A 레일 ]
       GND ◄── [ 공통 GND ]
       DIN ◄── [ 470Ω 보호 저항 ] ◄── XIAO D1 (GPIO2)

 [ 배기 / 냉각 소형 블로워 팬 (5V) ]
       5V (+) ◄── [ 5V 2A 레일 ]
       GND (-) ──► 2N2222 NPN Transistor (Collector)
                   2N2222 Emitter ──► [ 공통 GND ]
                   2N2222 Base ◄── [ 1kΩ 저항 ] ◄── XIAO D3 (GPIO4, PWM 제어)
                   (팬 양단에 1N4007 플라이백 역방향 다이오드 병렬 장착)
```

## 5. 제작 및 배선 시 주의사항 (Checklist)

1. **전원 그라운드(GND) 결선**:
   * 24V 히터 대전류 라인과 5V 센서 라인의 GND는 반드시 **XIAO 보드의 GND 핀 근처에서 한 점(Star Ground)**으로 묶어야 아날로그 센서(MQ-137, DS18B20)에 노이즈가 타지 않습니다.
2. **MQ-137 사전 예열**:
   * 가스 센서는 시연 최소 48시간 전부터 상시 통전(5V 인가)해 두어야 유효한 기준선(R0)이 잡힙니다.
3. **서모스탯 부착 위치**:
   * KSD301(45℃) 바이메탈 센서는 **캡톤 히터 알루미늄 방열판 표면에 직접 써멀 구리스로 밀착**시켜 히터 과열 시 MCU와 무관하게 1초 안에 24V 전원을 끊도록 배치합니다.
