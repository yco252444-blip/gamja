# Oink 지능형 미생물 자율 관리 시스템 구현 명세서 (Implementation Specification)

**문서 번호**: OINK-TECH-SPEC-v1.0  
**작성일**: 2026-10-09  
**대상 시스템**: 제14회 Creative Space G 출품용 "Oink (AI 기반 자율 미생물 관리 및 초절전 제어 시스템)"  
**핵심 아키텍처**: 내부 로컬 직결 무선망(ESP-NOW P2P) + 단일 게이트웨이 노드(Wi-Fi STA & MQTT) 하이브리드 분산망

## 1. 시스템 통신 및 전원 토폴로지 (System Topology)

## 3. 노드 간 데이터 패킷 구조체 정의 (ESP-NOW Structs)

보드 1과 보드 2는 아래 C 구조체(Struct)를 패킷으로 만들어 보드 3(게이트웨이)과 서로에게 전송합니다.

### 3.1 센서 텔레메트리 패킷 (보드 1 ➔ 보드 2, 보드 3)
```cpp
// 패킷 크기: 20바이트 (전송 시간: 0.2ms 미만)
typedef struct __attribute__((packed)) {
    uint8_t  node_id;        // 1 (보드 1)
    uint32_t seq;            // 시퀀스 번호
    float    core_temp;      // 심부온도 (DS18B20, ℃)
    float    ambient_temp;   // 외기온도 (BME280, ℃)
    float    ambient_hum;    // 외기습도 (BME280, %)
    uint16_t co2_ppm;        // CO₂ 농도 (CM1106S4, ppm)
    uint16_t nh3_raw;        // 암모니아 ADC (MQ-137, 0~4095)
} SensorPacket;
```

### 3.2 제어 및 전력 상태 패킷 (보드 2 ➔ 보드 3)
```cpp
// 패킷 크기: 16바이트 (전송 시간: 0.15ms 미만)
typedef struct __attribute__((packed)) {
    uint8_t  node_id;        // 2 (보드 2)
    uint8_t  heater_state;   // 0: OFF, 1: ON (조기차단 반영)
    uint8_t  fan_duty;       // 0~100 (%)
    uint8_t  safety_tripped; // 0: 정상, 1: 비상 안전 차단 발생
    float    bus_voltage;    // 24V 버스 전압 (INA219, V)
    float    current_ma;     // 소비 전류 (INA219, mA)
    float    power_mw;       // 소비 전력 (INA219, mW)
} ControlPacket;
```

## 4. 보드별 세부 구현 명세 (Node Implementation)

### 4.1 [보드 1] SENSOR NODE (미생물 환경 계측 전담)
* **하드웨어 핀맵**:
  * `D0 (GPIO1)`: MQ-137 Analog Out (10k:12k 분압 경유)
  * `D2 (GPIO3)`: DS18B20 OneWire (4.7kΩ 풀업)
  * `D4 (GPIO5)`: BME280 I2C SDA
  * `D5 (GPIO6)`: BME280 I2C SCL
  * `D6 (GPIO43)`: CM1106S4 Hardware UART TX
  * `D7 (GPIO44)`: CM1106S4 Hardware UART RX
* **동작 로직**:
  1. 부팅 즉시 Wi-Fi 모드를 `WIFI_STA`로 설정하고 ESP-NOW 초기화 (`esp_now_init()`).
  2. 외부 공유기 연결 루틴은 **일체 실행하지 않음** (외부 Wi-Fi 연결 딜레이 차단).
  3. 1초 주기로 `CM1106S4` NDIR CO₂ 패킷 파싱 + `DS18B20` 논블로킹 계측.
  4. 수집 즉시 `SensorPacket`을 브로드캐스트(`FF:FF:FF:FF:FF:FF`) 또는 보드 2, 3의 MAC 주소로 전송.

---

### 4.2 [보드 2] CONTROL & SAFETY NODE (히터 발열 및 화재 차단 전담)
* **하드웨어 핀맵**:
  * `D3 (GPIO4)`: 5V 블로워 팬 PWM (2N2222 트랜지스터 구동)
  * `D4 (GPIO5)`: INA219 I2C SDA
  * `D5 (GPIO6)`: INA219 I2C SCL
  * `D8 (GPIO7)`: IRLZ44N MOSFET Gate (100Ω 직렬, 10kΩ 풀다운)
* **동작 로직**:
  1. 부팅 즉시 ESP-NOW 초기화 및 수신 콜백(`esp_now_register_recv_cb`) 등록.
  2. 보드 1로부터 `SensorPacket` 수신 시:
     * 심부 온도 변화율 추세 분석 ($dT/dt$).
     * 목표 온도(37.0℃) 접근 시 미생물 자가발열 예측을 통한 **Predictive Early-OFF** (히터 선제 차단) 판정.
  3. INA219를 통해 1초마다 실시간 소비 전력(mW) 계측.
  4. 제어 결과를 `ControlPacket`에 담아 보드 3(게이트웨이)으로 ESP-NOW 송신.
  5. **Fail-Safe 인터록**: 보드 1로부터 15초 이상 패킷 미수신 시 히터 강제 즉시 OFF.

---

### 4.3 [보드 3] LOCAL UI & EDGE GATEWAY NODE (총괄 게이트웨이)
* **하드웨어 핀맵**:
  * `D1 (GPIO2)`: WS2812B 신호등 LED DIN (470Ω 저항 경유)
  * `D2 (GPIO3)`: 비상 알림 부저
  * `D4 (GPIO5)`: 0.96" OLED I2C SDA
  * `D5 (GPIO6)`: 0.96" OLED I2C SCL
* **동작 로직 (듀얼 스택)**:
  1. **내부 통신 (ESP-NOW)**:
     * 보드 1과 보드 2의 패킷을 1초마다 실시간 수신.
     * OLED에 귀여운 미생물 표정 캐릭터와 한 줄 행동 가이드 표출 ("정상 발효 중", "물 한 컵 투입" 등).
     * WS2812B 3색 신호등 갱신 (초록: 정상, 노랑: 주의, 빨강: 위험).
  2. **외부 게이트웨이 (Wi-Fi STA + MQTT)**:
     * 백그라운드 FreeRTOS Task에서 외부 Wi-Fi 연결 상태를 비동기로 감지 (`WiFi.status() == WL_CONNECTED`).
     * **와이파이가 잡혔을 때**: Railway MQTT 브로커(포트 18830)로 `oink/telemetry/live` 토픽에 JSON 패킷 발행.
     * **와이파이가 끊겼을 때**: MQTT 발행만 일시 정지하고, 로컬 OLED 및 LED 제어는 **단 1ms의 딜레이도 없이 100% 정상 작동**.

## 6. 장애 발생별 시스템 생존 매트릭스 (Fail-Safe Verification)

| 장애 상황 (Fault Scenario) | 보드 1 (센서) | 보드 2 (히터 제어) | 보드 3 (UI/게이트웨이) | 시스템 안전 상태 |
|---|---|---|---|---|
| **집 공유기 전원 OFF / 인터넷 단선** | 영향 없음 (ESP-NOW 정상) | 영향 없음 (ESP-NOW 정상 제어) | OLED/LED 로컬 UI 100% 동작 (클라우드 송신만 대기) | **생명 유지 100% 정상 작동 (Edge Autonomy)** |
| **보드 1 통신 케이블 분리** | 자체 재시도 | 15초 경과 후 히터 강제 OFF | OLED에 "센서 노드 확인 요망" 경고 표출 | **과열 화재 원천 방지 (Fail-Safe)** |
| **ESP32 펌웨어 완전 프리징/오작동** | - | - | - | **45℃ KSD301 서모스탯 물리 차단 (화재 0%)** |
| **외부 인터넷 복구 완료** | 영향 없음 | 영향 없음 | Wi-Fi 재연결 감지 즉시 Railway/Vercel 스트리밍 자동 재개 | **무중단 자동 복구 (Auto Recovery)** |

## 7. 결론 및 심사위원 대응 요약
본 구현 명세서는 **"센서-히터 간 필수 화재 안전 루프(ESP-NOW)"**와 **"원격 모니터링 통신 루프(Wi-Fi STA 게이트웨이)"**를 완전히 분리하여, 네트워크 단절이나 외부 환경 변화에도 기기 단독으로 미생물 생명을 100% 유지하는 완벽한 가전 완제품 수준의 아키텍처를 증명합니다.
